# Broker Valet website

Single-page marketing site for Broker Valet: renewal and policy admin for insurance brokers.

Live at **https://brokervalet.avanext.ai**

- `index.html` is the whole page (inline CSS and JS, no build step).
- `logo-mark.png` / `logo-word.png` are the header logo; `logo-mark.png` is also the tab icon.
- `demo.mp4` is the demo video that plays in the "Watch the demo" pop-up.
- Hosted on GitHub Pages from the `main` branch. `CNAME` holds the custom domain.
- DNS: a `CNAME` record `brokervalet` → `harini-prabakaran-16.github.io` on avanext.ai (Crazy Domains).

## Deploying

Push to `main`. GitHub Pages republishes in about a minute.
